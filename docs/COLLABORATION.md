# 多人使用与源码协作

## 创作任务并行

一台主机运行一个急急服务，所有同事连接这台主机。每个浏览器使用独立会话标识，每部片创建独立项目。项目拥有自己的对话、资产、分镜、确认、后台任务、生成记录和保存锁。

同一项目用占用记录互斥，正常空闲占用在 90 秒未续约后可释放；运行、暂停或停止中的任务继续保护项目，不能因页面离开就由另一人接管。切换到别的项目会释放自己此前空闲项目的占用。遇到“这个项目正有人在用”，应换项目或等待对方完成。

ComfyUI 是共享生成队列：项目可并行准备和提交，实际渲染速度取决于队列和显存；项目隔离不代表每个人都有独立 GPU。全局服务配置、凭据与长期偏好仍共享，由主机负责人统一维护。

不要在两个 Python 服务进程间共享同一个 cache_root。当前占用表和锁在进程内，不能处理双进程 / 多主机写入同一项目；需要独立缓存目录或以后接入数据库锁。

## 开发代码并行

仓库默认分支建议 main。每个人 / 每个修改任务单独建分支，例如 fix/table-upload 或 feat/visual-styles；以 Pull Request 合并。先同步 main 再修改，提交前只检查实际源码文件，避免把本机设置和项目素材加入提交。

涉及提示词确认、引用绑定、项目隔离、计费任务或 Skill 上下文的修改，需要相应回归检查和另一位开发者审核。出现冲突时逐处确认双方行为，不整文件覆盖。用户尚未接受的建议不应成为默认行为。

AGENTS.md 是 Codex 的仓库指导，.cursor/rules 中的规则为兼容编辑器提供同一约束；skills/*.md 是应用内导演经验。三者用途不同：开发规则不传给影片模型，导演 Skill 不授权开发工具执行操作。

## 更新主机

在独立目录检查新版本；备份源码和真实 cache_root，等待当前创作任务完成再停止急急并更新。保留 config.json、secrets.json 及原缓存路径，重启后检查旧项目可读、静态页面可加载和同事连接地址。不要用示例配置覆盖真实配置，不停止 ComfyUI，不重新提交已受理的视频。

GitHub 储存代码，不会自动部署或替代局域网服务。源码协作与视频创作并行是两套机制。
