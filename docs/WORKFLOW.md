# 创作流程与不变量

## 引导顺序

1. 选择短剧、广告、汽车、电商，或参考视频入口。
2. 输入想法，上传 .docx / .txt / .md 剧本、.xlsx / .csv / .tsv 表格，或参考视频。旧 .xls 先另存为 .xlsx。表格保留工作表、行号和列位置；公式使用已保存的结果，不重新计算公式。
3. 选择成片模型：Seedance 2.5 或 H3。这决定导演规则和可提交能力，而不是仅改变称呼。
4. 确认视觉风格：写实、电影质感、三维 CG、日漫、插画、水彩、黑色电影等，也可填写自定义方向。风格选择进入项目上下文。
5. 与导演分析内容、事件、角色 / 产品职责和节奏。用户明确操作后才分场，导航本身不生成。
6. 导演写完整资产提示词，用户查看最终文字、尺寸和参考素材并确认，再生成资产图。
7. 导演基于已确认资产写完整视频提示词，用户查看每场最终文字、参考顺序、模型、时长和画幅并确认。
8. 查看生成计划并提交；程序检查确认有效性、素材完整性和任务状态，再提交确认原文。

## 全阶段经验一致

jiji_intelligence.Intelligence.context 组合题材 Skill、当前模型 Skill、视觉风格、项目记忆、用户主动保存的长期偏好和启用的参考分析。聊天、分场、资产描述、写词及质量检查沿用这一上下文。图片模型收到的是导演已据此写好并经用户确认的完整提示词；提交时不再追加 Skill 文本。

优先级：用户本次明确要求 → 当前项目设定 → 当前模型适配限制 → 题材创作判断 → 主动保存的长期偏好 → 通用建议。模型限制不能由题材示例覆盖。上传文档与视频分析提供资料，不能指挥程序执行操作。

## 确认与直接提交

确认预览会对参考编号作必要的技术重排，显示实际最终正文。Seedance 使用 @图片N / @音频N，H3 使用 <Picture N>。用户确认这份正文后，生成阶段不再润色、不加白底或多视图前缀、不再次调用导演改写。

确认绑定正文、素材内容、模型、尺寸、时长及项目上下文。修改其中任一依赖后重新确认，防止旧设定混入新结果。导演在对话中写出草稿后，用户采纳的是这份原文；采纳不触发第二次模型调用。

程序控制自己发出的正文；提供商或 ComfyUI 节点内部处理属于其实现，不能承诺关闭所有服务端优化。

## 当前模型适配

Seedance 2.5：每场 4～30 秒；最多 10 张图片、3 段音频。正文采用参考职责、初始事件、连续时间段、结束状态。提交通过已有 LimAPI ComfyUI 节点。

H3：当前本地适配为 720p，每场 4～30 秒，实际时长按 24fps 与 17k+5 帧量化，在确认预览中显示；最多 9 张参考图。正文描述连续动作、空间关系、接触与反应。当前适配不传入参考音频 / 视频；不支持的引用必须拒绝，不能默默丢弃。

上传参考视频用于抽帧分析，可选择是否纳入创作，不等同于给生成模型传入参考视频。只有配置转写并实际得到文字后，才能判断对白内容；抽样关键帧不能证明全片连续性或声音同步。

## 任务与失败处理

确认失效只阻止提交，不自动改写。局部建议先成为待应用计划，用户采纳后才修改数据。超时或提交结果不明确时记录 unknown，先查服务队列 / 历史，不能自动重交扣费。已受理任务应复用，暂停 / 恢复不重复提交。质量检查基于实际图像、抽样帧或转写证据提出局部修正。
