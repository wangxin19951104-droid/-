# 急急 · 导演创作工作台

围绕一部视频逐步推进：选择类型 → 输入想法、剧本、表格或参考视频 → 选择 Seedance 2.5 / H3 → 确认视觉风格 → 导演对话 → 确认资产提示词 → 生图 → 确认视频提示词 → 提交生成。

用户确认的最终提示词直接进入提交接口。参考编号在确认预览中按实际上传顺序重排；确认后不调用模型再改写。素材、时长、模型或创作方向变化时，旧确认失效，需要重新预览确认。

## 首次在 Windows 安装

1. 安装 Python 3.11 或 3.12，确保可以运行 python 或 py -3。
2. 解压 / 克隆到独立目录，双击 setup.bat 安装 Pillow 并建立本地配置。
3. 将 FFmpeg 放入 PATH；视频上传解析、抽帧和后期处理需要 ffmpeg，ffprobe 可提供更完整的信息。
4. 在主机启动原有 ComfyUI，默认地址为 http://127.0.0.1:8189。模型权重、节点和服务凭据由 ComfyUI 管理，仓库不打包这些文件。
5. 双击“启动急急.bat”。本机访问 http://127.0.0.1:8765，配置导演接口的密钥；或在环境变量中设置 JUNFLOW_API_KEY。

默认导演配置沿用当前工作流：gpt-6.1-sol、reasoning_effort=xhigh（界面“极高”）、现有兼容接口地址。模型名称与推理参数须由该服务支持；填写配置不会验证服务能力。参考视频分析需要接口支持图像输入，转写还需额外配置转写模型。

bootstrap.py 首次生成 config.json，缓存路径自动转为仓库内 cache 的绝对路径；已有配置保持原样。不要将空 cache_root 的示例直接当作配置运行 server.py，否则旧默认会回到 W 盘。已有桌面部署可继续使用其原缓存路径。

## 与同事并行使用

由一台主机运行急急和 ComfyUI，同事通过浏览器访问主机打印的“同事访问”地址。0.0.0.0 是监听地址；它不是浏览器访问地址。每个人创建自己的项目，项目状态和后台任务隔离；同一项目同时编辑会被占用检查阻止。

当前示例监听局域网，应用没有账号和角色权限。浏览器会话 ID 用于避免编辑冲突，不代表身份认证；局域网使用者共享模型配置、生成资源及全局偏好。只在受信任的局域网部署。GitHub 仓库可见性不会给急急网页增加登录功能。

## 开发验证

在独立测试目录运行：

~~~text
python -m pip install -r requirements.txt
python tools/run_checks.py
node tools/check_web.mjs
~~~

测试在临时目录造素材，模型 / 生成接口由模拟对象替代。HTTP 测试会启动临时本地服务；视频解析测试只生成两秒的本地测试片，需要 FFmpeg。run_checks.py 限制网络连接到测试自己创建的 HTTP 服务，阻止误调用真实接口。GitHub Actions 配置 Windows + Python 3.11/3.12，并执行这些检查。

config.json、secrets.json、实际项目、上传素材、生成结果、日志和缓存不进入版本控制。公开仓库管理源码与开发文档，任何人可查看和下载；项目数据留在主机并需要另外备份。此目录是从现用桌面版本整理出的独立仓库准备版，未覆盖桌面应用。
